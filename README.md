# GAME SALES & PLAYER MARKET INTELLIGENCE

1. Project Introduction
This project analyses historical video game sales data to identify the factors that influence commercial success. It examines game genres, gaming platforms, publishers, and regional sales to help a global gaming company make better business decisions.

2. Problem Statement
The gaming industry is highly competitive. Companies need to understand which games, genres, and platforms generate the highest sales to make informed decisions about future game releases.

3. Project Objectives
- Identify the highest-selling gaming platforms.
- Determine the most successful game genres.
- Analyse game sales trends over time.
- Compare sales across different geographical regions.
- Identify top-performing publishers.
- Provide business recommendations based on the findings.

4. Dataset Overview
The dataset contains historical video game sales information.

Key columns include:
- game_id
- name
- platform
- genre
- publisher
- developer
- release_year
- na_sales
- eu_sales
- jp_sales
- other_sales
- global_sales

5. Data Cleaning
The data cleaning process involved:
- Checking for missing values.
- Removing duplicate records where necessary.
- Correcting data types.
- Handling missing values.
- Creating additional analytical columns.

6. Exploratory Data Analysis
The analysis focused on:
- Platform sales performance.
- Genre sales performance.
- Average sales per game.
- Sales trends over time.
- Publisher performance.
- Regional gaming preferences.
- Top 10 best-selling games.

7. Visualizations
Graphs and charts were created using Python to communicate the findings, including:
- Top 10 best-selling games.
- Global sales by platform.
- Sales by genre.
- Video game sales trends over time.
- Regional sales comparisons.

8. Tools and Technologies
- Python
- Pandas

9. Business Recommendations
1. Invest more in platforms with strong sales performance.
2. Focus on genres with high commercial potential.
3. Study regional gaming preferences before launching games.
4. Partner with successful game publishers.
5. Monitor market trends when planning future releases.
6. Use historical sales data to support marketing decisions.

10. Conclusion
The project demonstrates how data analysis can help identify successful gaming platforms, genres, publishers, and regional preferences. These insights can support better business decisions and improve future game release strategies.
